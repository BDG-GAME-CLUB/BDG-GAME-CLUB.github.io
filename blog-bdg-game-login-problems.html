Seven common login issues

1. The address is not the one you expect

Look for spelling changes, extra words and unusual domain endings. Do not sign in through an unsolicited message or tip-group link. Navigate using a source you independently trust.

2. The mobile number format is wrong

Confirm the country code and use the number attached to the account. Spaces or an old number can prevent a match.

3. The password is incorrect

Check uppercase characters and typing language. Use the verified password-reset flow instead of repeatedly guessing.

4. The OTP is delayed

Wait briefly, check reception and blocked-message settings, and avoid requesting many codes in quick succession. Never read an OTP aloud to “support.”

5. A temporary limit is active

Repeated attempts may trigger a short security lock. Pause, then use the official recovery option. A third party cannot safely bypass the lock.

6. The app or browser is outdated

Install trusted operating-system and browser updates. If using an app, verify its source before updating or reinstalling.

7. The network is unstable

Switch from unreliable public Wi‑Fi to a trusted connection. Avoid financial or account activity on a shared device.

Keep the account secure

  • Use a password that is not used for email or banking.
  • Turn on extra verification if the service provides it.
  • Review recent logins and payment history after access returns.
  • Sign out of devices you do not recognise.
Never install screen-sharing or remote-access software for a person claiming they can fix a login.

What if nothing works?

Use only the verified support channel and provide non-secret details such as the time of the error and a screenshot with personal information covered. Do not send a password, OTP, PIN or full payment credential.
